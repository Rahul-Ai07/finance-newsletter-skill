# Template: Promotional

Use when: discount, limited-time offer, tiered pricing, referral bonus, sign-up incentive.

## Structure
1. **Subject line** — lead with the concrete offer (specific number/amount), not generic "Special offer inside"
2. **Preheader** — the deadline or condition, if real
3. **Hero headline** — the offer, stated plainly with the number
4. **Hero subheading** — the condition/eligibility in one line, plus genuine urgency if applicable
5. **Body** — why the offer is worth acting on now: concrete value, not hype. One proof point (customer count, rating) if available.
6. **Primary CTA** — action-oriented, first-person where natural: "Claim My Bonus," "Start Saving Now"
7. **Fine print** — terms, expiration date, eligibility, and the **all-in cost of credit** (where the offer touches a loan/credit product) stated as clearly as the headline number, not buried
8. **Footer** — standard footer + RBI-aligned compliance disclaimer

## RBI compliance guardrails (India)
There is no blanket restriction on running promotions — RBI regulates *how* they're disclosed, not whether they can be sent:
- **Fair Practices Code**: every material term (interest rate, APR, fees, penalties) must be disclosed transparently and as prominently as the headline offer — not in unreadable fine print.
- **Digital Lending Guidelines (2022)**: no dark patterns — no pre-ticked consent, no implied automatic credit-limit increases, no unsolicited push of a loan offer via manipulative UX. For any credit/lending promo, include a Key Fact Statement-style all-in-cost figure.
- **No fabricated urgency on credit products**: "only 3 spots left" / fake countdown timers on lending or credit offers are a supervisory red flag (implies unequal access to credit) as well as a trust risk. Only use real, verifiable urgency (an actual expiry date, an actual limited allocation).
- If the user requests fabricated scarcity for a regulated product, flag it rather than silently complying.

## Notes
- If this is a recurring/evergreen offer, don't imply false scarcity — frame the value proposition instead of manufacturing a deadline.
