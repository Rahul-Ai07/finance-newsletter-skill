# 🎯 Customer Validation - Week-by-Week Execution Checklist

## WEEK 1: Research & Outreach Setup

### Day 1-2: Define Your Target List
- [ ] Create LinkedIn search saved searches:
  - Search 1: "Growth Manager" + fintech + India + open to tools
  - Search 2: "Marketing Manager" + lending + India
  - Search 3: "Head of Marketing" + NBFC + India
- [ ] Create Twitter search list for fintech community
- [ ] Identify 5-10 personal connections in fintech
- [ ] Create outreach spreadsheet with columns:
  - Name, Email, LinkedIn URL, Company, Role, Outreach Date, Response

**Target:** Build list of 50-80 potential early users

### Day 3-4: Create Messaging
- [ ] Write 3 LinkedIn message variants (A/B/C)
- [ ] Write 3 email subject lines
- [ ] Create full email template
- [ ] Create early access landing page (or just use: http://127.0.0.1:3000)
- [ ] Test all messages with 1 friend for feedback

**Target:** Polished, ready-to-send messaging

### Day 5-7: Start Outreach
- [ ] Send 15 LinkedIn DMs (spread over 3 days)
  - Track responses in spreadsheet
  - Note: Expect 20-30% response rate
- [ ] Send 10 emails (spread over 2 days)
  - Use email tracking if possible (Superhuman, HubSpot, etc.)
  - Note responses
- [ ] Engage in 3-5 fintech Twitter conversations
  - Reply thoughtfully, mention tool if relevant
  - Not salesy - just part of conversation

**Target:** 15-20 outreach messages sent, 3-5 responses

### Week 1 Success Criteria
- [ ] 50-80 person target list created
- [ ] 30+ outreach messages sent
- [ ] 5+ responses received ("interested" or "tell me more")
- [ ] 2-3 early access sign-ups

## WEEK 2: Onboarding & Setup

### Day 1-2: Handle Early Signups
- [ ] Email each sign-up with:
  - [ ] Welcome message
  - [ ] Link to app (http://127.0.0.1:3000)
  - [ ] 1-page quick start guide
  - [ ] Offer optional 15-min walkthrough call
- [ ] Schedule any walkthrough calls
- [ ] Continue daily check-in emails: "How's it going?"

### Day 3-4: Run Walkthrough Calls
- [ ] Do 15-min walkthrough with each interested user
  - Use script from Validation Toolkit
  - Share screen or send video demo
  - Answer questions
  - Explain feedback call in Week 4
  - Note: Record if possible (for your learning)

### Day 5-7: Mid-Week Check-In & More Outreach
- [ ] Send 15 more LinkedIn DMs to new prospects
  - Look for: Comments on fintech posts, active users
- [ ] Follow up with non-responders (1 follow-up per person)
- [ ] Send daily "how's it going?" to active users
  - "Curious if you've had a chance to try it yet!"
  - "Any feedback on the Market Update template?"
  - Keep it short & casual

**Target:** 15-20 total sign-ups, 8-10 active users

### Week 2 Success Criteria
- [ ] 3-5 walkthrough calls completed
- [ ] 15-20 sign-ups total
- [ ] 8-10 users logged in
- [ ] 3-5 users generated ≥1 newsletter
- [ ] 30+ more outreach messages sent

## WEEK 3: Engagement & Usage

### Daily Task: Monitor & Encourage Usage
- [ ] Check app dashboard for active users
  - Who logged in? Who generated newsletters?
- [ ] Send daily encouragement to low-usage users:
  - "Curious how it went with [Template] template?"
  - "Want help getting started?"
  - "Quick question: What would make this useful for you?"

### Day 1-3: Schedule Feedback Calls
- [ ] Email: "Let's chat about your experience next week!"
- [ ] Send Calendly link with 4 time slot options
- [ ] Aim for Day 12-14 (end of their 2-week trial)
- [ ] Target: Schedule 8-10 calls with active users

### Day 4-7: Continue Outreach
- [ ] Send 10-15 more LinkedIn DMs
  - Target: People who haven't responded yet
  - Use different angle/message
- [ ] Send 5-10 more emails
  - Target different segment if possible
- [ ] Engage in more Twitter conversations

**Target:** 20-25 total sign-ups, 12-15 active

### Week 3 Success Criteria
- [ ] 20-25 sign-ups total
- [ ] 12-15 users logged in (60%+ activation)
- [ ] 8-10 users generated ≥2 newsletters
- [ ] 8-10 feedback calls scheduled
- [ ] 30+ more outreach messages sent

## WEEK 4: Feedback Interviews

### Day 1-2: Prepare Interview Materials
- [ ] Print 10 copies of interview script from Toolkit
- [ ] Create Google Doc to track interview notes
- [ ] Prepare Zoom/Google Meet links
- [ ] Set up recording (if getting permission)

### Day 3-7: Run Feedback Interviews (5-7 calls)
**Each call: 30 minutes**

- [ ] Run structured interview (see Toolkit)
- [ ] Take detailed notes on:
  - [ ] Problem validation: Do they have the pain point?
  - [ ] Solution fit: Does this solve it?
  - [ ] Compliance value: Is it critical?
  - [ ] Willingness to pay: At what price?
  - [ ] Feature requests: What's missing?
  - [ ] Referrals: Would they recommend?
- [ ] Record key quotes
- [ ] Ask permission for case study later
- [ ] Thank them & tell them when you'll follow up

**Interview Tracker Columns:**
| Name | Problem | Solution | Compliance | Price | Top Feature | Referrals | Notes |
|------|---------|----------|-----------|-------|-------------|-----------|-------|
| John | Yes | Good | Critical | $150 | HubSpot | 2 | Loved variants |
| Sarah | Yes | Good | Important | $100 | Analytics | 1 | Compliance key |

### Mid-Week: Run 5 Calls
- [ ] Complete interviews with 5 active users
- [ ] Record responses in tracker

### Day 7+: Run 5 More Calls
- [ ] Complete interviews with 5 more users
- [ ] Update tracker with responses

**Target:** 10 interviews completed

### Week 4 Success Criteria
- [ ] 10 structured interviews completed
- [ ] All responses logged in tracker
- [ ] Problem validation: 70%+ confirm ✅
- [ ] Solution fit: 60%+ say "good" ✅
- [ ] Willingness to pay: 50%+ at $100+/month ✅

---

## WEEK 5: Analysis & Decision

### Day 1-2: Analyze Results
- [ ] Review all 10 interview notes
- [ ] Calculate metrics in spreadsheet:
  - [ ] % who confirmed problem
  - [ ] % who confirmed solution
  - [ ] Avg willingness to pay
  - [ ] Top 3 feature requests (by frequency)
  - [ ] Total referrals offered
- [ ] Calculate: Is this GREEN / YELLOW / RED light?

**Scoring:**
```
GREEN LIGHT (All ✅):
- 70%+ problem validation
- 60%+ solution fit
- 50%+ willing to pay $100+
- 5+ referrals
- 3+ repeated feature requests

YELLOW LIGHT (Some ✅):
- Problem confirmed but needs iteration
- OR lower price sensitivity than hoped
- OR 1-2 critical features missing

RED LIGHT (Multiple ✗):
- <50% problem validation
- <30% solution fit
- <$50 avg willingness to pay
- 0 referrals
```

### Day 3: Create Decision Summary
- [ ] Write summary document: VALIDATION_RESULTS.md
  - [ ] Quantitative results
  - [ ] Qualitative insights
  - [ ] GO/YELLOW/RED decision
  - [ ] Top 3 next actions

## IF GREEN LIGHT: Scale to Beta (Week 5 onwards)

### Day 4-5: Prepare Paid Beta Offer
- [ ] Email template for beta pricing offer:
  ```
  Subject: [Name], become a founding customer?
  
  Hi [Name],
  
  Thanks for testing. Your feedback was invaluable.
  
  Based on your use cases, we're launching a paid beta:
  - $50-90/month (80% off eventual pricing)
  - All founders lock in that price forever
  - Direct access to me for feature requests
  
  Interested? Reply with "YES" and I'll send details.
  
  [Your Name]
  ```
- [ ] Create Stripe billing page (or manual payment process)
- [ ] Prepare onboarding docs for paid users

### Day 6-7: Send Beta Offers
- [ ] Email all 12 users willing to pay $100+/month
  - Offer: $50-90/month (80% discount)
  - Lock-in: "Forever founders price"
- [ ] Target: 5-10 converting to paid
- [ ] Track: Who says YES, who says MAYBE, who says NO

### Week 5 Success Criteria (GREEN LIGHT)
- [ ] Decision document written & reviewed
- [ ] Beta offer sent to 12+ users
- [ ] 3-5 users convert to paid customers
- [ ] $150-400 MRR by end of week (3-5 paying customers × $50-90)

---

## IF YELLOW LIGHT: Iterate & Retry (Week 5-6)

### Day 1-3: Fix Top Issue
- [ ] Identify #1 blocking problem from interviews
- [ ] Examples:
  - "Compliance checking isn't accurate enough"
  - "Missing HubSpot integration"
  - "Price is too high"
  - "Doesn't handle [specific use case]"
- [ ] Build/fix in 2 weeks
- [ ] Or: A/B test lower price ($49/mo) with next cohort

### Day 4-7: Re-Test with Cohort 2
- [ ] Identify 15 new potential users (different segment if possible)
- [ ] Repeat Weeks 1-2 outreach with Cohort 2
- [ ] Same validation process with iteration built in
- [ ] See if fix moves needle on metrics

### Week 5-6 Success Criteria (YELLOW LIGHT)
- [ ] #1 issue identified & communicated
- [ ] Action plan created (build feature OR lower price)
- [ ] Cohort 2 outreach started
- [ ] Plan to re-test with improved product

---

## IF RED LIGHT: Diagnose & Pivot (Week 5-6)

### Day 1-2: Root Cause Analysis
- [ ] Re-interview 3 users who rejected it
- [ ] Deep dive: "What would it take to make you say yes?"
- [ ] Possible answers:
  - "Problem doesn't actually exist" → Wrong segment
  - "Solution approach is wrong" → Pivot solution
  - "Price is way too high" → Reduce price 50%+
  - "Missing critical feature" → Build it

### Day 3-7: Decide Path
Choose ONE:
- [ ] **A) Pivot to Different Segment**
  - Test with agencies instead of NBFC
  - Test with wealth platforms instead of lending
  - Re-run validation with new segment
- [ ] **B) Redesign Solution**
  - Add the critical missing feature
  - Change core value prop based on feedback
  - Re-test with Cohort 2
- [ ] **C) Pause & Pursue Different Idea**
  - Market signal suggests this may not be viable
  - Better to learn now with 0 customers than later

### Week 5-6 Success Criteria (RED LIGHT)
- [ ] Root cause identified
- [ ] Clear pivot direction chosen
- [ ] Decision documented with reasoning
- [ ] Next steps defined
